# Special Pickaxes 4.0 — guía breve

Sostén una reliquia. Su descripción normal dice qué hace; mantén SHIFT sobre el
objeto para ver el manual y tus teclas actuales. No hay panel permanente.

## Tus controles

Opciones → Controles → **Special Pickaxes**. Puedes reasignar todas las acciones:

| Acción | Por defecto |
|---|---|
| Activar habilidad directa | R |
| Secundaria: liberar/desconectar | G |
| Cambiar modo o transformación | C |
| Entrar/salir de selección | B |
| Confirmar una selección lista | Enter |
| Cancelar | V |
| Pausar/reanudar trabajo | K |

SHIFT sirve para leer el manual, no para activar poderes. Clic derecho no dispara
habilidades. Las teclas de otros mods pueden coincidir: reasígnalas en Controles.
Cada manual muestra únicamente las acciones que corresponden a su artefacto.

## Dos maneras de jugar

**Directos:** apunta, pulsa Activar. Usa Modo solamente si el objeto lo admite.
Meridian marca A/B; Lodestar marca y después regresa; los dominios se liberan
con Secundaria. Worldloom y Keystone construyen con material secundario real.

**Regionales:** Selección → clic izquierdo en las esquinas → espera LISTO →
Confirmar. El análisis comienza solo. Atlas/Tessellator tienen origen y destino;
Crucible/Chronicle, una región. Worldbreaker conserva estos programas, pero su
nuevo modo **Convergencia** no requiere selección.

**Worldbreaker:** Convergencia fractura un anillo sin vaciar el núcleo y levanta
un santuario central si hay espacio y materiales. Lleva bloques de construcción.
No es invulnerabilidad ni permiso para alterar zonas protegidas.

Cancelar interrumpe trabajos, dominios, selección y enlaces. Cambiar herramienta,
morir, desconectarte o cambiar de dimensión cancela operaciones temporales.
Una región descargada se pausa sin cargar chunks por la fuerza.

## Costes

Sin energía, mana ni combustible. Hay durabilidad, cooldown y bloques reales.
Efficiency, Fortune, Silk Touch, Unbreaking y Mending funcionan con niveles altos.
Consulta SHIFT para la restricción importante de cada objeto, no para fórmulas internas.

Instala `special-pickaxes-1.20.1-4.0.0.jar` en cliente y servidor, reemplazando el
anterior. Forge 1.20.1 / Java 17. Sin recetas, minerales ni worldgen. Obtención por
creativo, `/give` o `/specialpickaxes grant Jugador ID` con permiso de administrador.
