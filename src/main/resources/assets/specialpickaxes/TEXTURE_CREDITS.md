# Referenced pickaxe textures

The Exodium, Iridium and Hellspec item icons in this mod are copied from the user's local Terramity 0.9.8 instance JAR, with permission granted by the user.

- Source: `assets/terramity/textures/item/exodium_pickaxe.png`
- Source: `assets/terramity/textures/item/iridium_pickaxe.png`
- Source: `assets/terramity/textures/item/hellspec_pickaxe.png`

The Worldbreaker runtime icon is an original 32×32 pixel-art redraw. Its generated visual concept was cleaned into a crisp sprite, using the pre-existing in-repository Worldbreaker icon as silhouette reference; the original texture remains preserved unchanged.
